## 如果進入後顯示後端版本不符

網頁需要 `SF-2026-v1.1-teacher` 後端（老師預覽帳號 D123456789）。
你若早已成功更新教師版 `Code.gs`，無需重新部署。
若尚未更新，才將本包 `Code.gs` 貼入**這門課專用的** Apps Script，執行 `setup()`、`checkSetup()`，再於「部署 > 管理部署 > 編輯原部署 > 新版本 > 部署」。這份 `Code.gs` 與上一版教師版相同，沒有變動，不會清除學生心得。
**不要將 `Code.gs` 上傳公開 GitHub**，因為它含有完整學生學號與姓名。

## 紅色「詐騙網站警告」要另外處理

Safari 顯示詐騙警告時，不要點選忽略警告、不要關閉安全瀏覽，也先不要在該頁輸入個資。
請確認 Safari 網址列當時顯示的是「本課 GitHub Pages 網址」還是「script.google.com/.../exec」或重導後的其他網址。
此警告是瀏覽器安全警告，不是 HTML 佔位符造成；填入 URL 不保證警告會消失。本環境無法測到 Google 線上後端是否可用，也無法代你解除安全封鎖。
