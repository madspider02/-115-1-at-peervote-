# 學習功能嚴重缺損｜10組教具名稱＋教師預覽（保留暖紫設計）

## 最不容易出錯的更新方式（推薦）

1. 進入目前**已可正常登入及評分**的本課 GitHub 儲存庫，編輯 `index.html`。
2. 在檔案最底部找到 `</body>`。
3. 開啟 `只新增10組教具名稱_貼在body前.txt`，將整段內容貼到 `</body>` **正前方**。
4. 提交變更。**不修改任何 `WEB_APP_URL`，不修改 Apps Script，不動既有評分紀錄。**
5. 畫面中 10 組的互評卡片、免評列表與個人歷次評分，都會自動顯示教具名稱。

這個方式能保留你目前已設好的 Apps Script /exec、學生識別與投票、紫色樣式。若你已經加過同一補丁，請先刪除舊補丁再貼新補丁，避免重複運作。

## 教師預覽帳號（尚未加入後端時）

若你前次**尚未完成**教師帳號更新，請將本包內 `Code.gs` 貼到此課專用 Google Sheet 的 Apps Script，執行 `setup()`、`checkSetup()`，並到「部署 → 管理部署 → 編輯原部署 → 新版本 → 部署」。

教師使用先前提供的帳號及姓名登入；正式學生仍為 38 人。教師能預覽所有週次，模擬評分不會寫入 Sheet。程式內的學生／教師身分資訊不可上傳公開 GitHub。

若你已完成教師登入，**不必再更換 Code.gs**。

## 若要使用完整原始碼版本

`index.html` 是加入教具名稱的完整暖紫版。此檔的 `WEB_APP_URL` 仍是原始佔位文字；**不要直接覆蓋目前可用的 index.html**，除非已把現有網頁的 `/exec` 網址複製回新的同一行。否則會失去連線。
